## Objective

Close remaining first-class daily-use holes: finish every Wayland drop, refresh the fallback cursor and toplevel icon when fractional scale changes, clear latched discrete wheel state on `axis_stop`, close X11 only when the toplevel is destroyed, and read WM hidden/focused state after MapWindow.

## In scope

1. Send `wl_data_offer.finish` on every `wl_data_device.drop` path (including failed receive and no-text offers) before destroying the offer.
2. On `wp_fractional_scale_v1` preferred-scale change, refresh the fallback shm cursor (sized from the 120ths scale) and reinstall `xdg_toplevel_icon_v1`.
3. Handle `wl_pointer.axis_stop` by clearing `axis_have_discrete` so later continuous axis events are not stuck.
4. X11 DestroyNotify closes only when the destroyed window is the toplevel. Recreate `_NET_WM_USER_TIME_WINDOW` if that child is destroyed. Select StructureNotify on the child so that path is live.
5. After MapWindow, read `_NET_WM_STATE` and ICCCM `WM_STATE` so `present()` honors startup hidden/iconic.
