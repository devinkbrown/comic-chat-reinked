Linux desktop backends (PR #13): `src/platform/event.zig`, `src/platform/x11.zig`, `src/platform/services.zig`, `src/platform/wayland.zig`.

## Objective

Keep a drag that enters the X11 window as a held primary (or secondary) button, and decode receive-only KOI8-R paste from Russian X11 / GTK sources.

## In scope

1. On EnterNotify, if Button1 or Button3 is already down and that button is not currently tracked as held, emit `.down` then queue the enter hover move. Do not synthesize middle-down (that would surprise-paste PRIMARY). Wayland `wl_pointer.enter` has no button state — skip.
2. Receive-only KOI8-R: MIME `text/plain;charset=KOI8-R` / `koi8-r` / `koi8r` plus the bare ICCCM `KOI8-R` target that xterm offers. Distinctive decode: `0xE1` → `А`.

- Wayland pointer-enter button restore
- Full IME editor, AT-SPI/UIA, outgoing source DnD
- COMPOUND_TEXT 94ⁿ CJK, ext-data-control, ISO-8859-10/14/16
