## Owner

Linux desktop backends (PR #13): `src/platform/x11.zig`, `src/platform/wayland.zig`, `src/platform/services.zig`.

## Objective

Accept GTK's receive-only `text/plain;charset=utf-16` on X11, treat `file://<local-hostname>/` drops as local paths, and send Wayland `data_offer.finish` only when `wl_data_device_manager` is bound at v3+.

## In scope

1. Intern `text/plain;charset=utf-16` / `utf16` on X11; decode like `UTF16_STRING`; include in TARGETS/XDND ranking.
2. `file:` URI hosts that match localhost, `127.0.0.1`, or `uname` nodename yield a local path.
3. Gate `data_offer.finish` on data-device version >= 3 so older compositors are not sent an unknown opcode.

## Out of scope

- UI chrome and the comic renderer
- KeymapNotify, ISO-8859-10/14/16, KOI8-U
- Full IME editor, AT-SPI/UIA, outgoing source DnD
- COMPOUND_TEXT 94ⁿ CJK, ext-data-control
- Accepting remote `file://` hosts
