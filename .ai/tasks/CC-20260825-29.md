## Owner

Linux desktop backends (PR #13): `src/platform/x11.zig`.

## Objective

Ship an ICCCM `WM_HINTS` icon pixmap and mask so non-EWMH window managers still show a taskbar/iconified mark. Modern WMs already read `_NET_WM_ICON`.

## In scope

1. Create a depth-1 32@1 / 64@2 pixmap + mask from `fillWindowMark`.
2. Set `IconPixmapHint` and `IconMaskHint` on every `WM_HINTS` write, including urgency updates.
3. Reinstall the pixmap on integer scale change and free it on close.

## Out of scope

- UI chrome and the comic renderer
- Full IME editor, AT-SPI/UIA, dedicated drop Event
- Wayland taskbar urgency, `_NET_WM_SYNC_REQUEST`, outgoing source DnD
- COMPOUND_TEXT 94ⁿ CJK and `ext-data-control`
