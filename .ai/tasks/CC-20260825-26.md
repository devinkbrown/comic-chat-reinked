## Owner

Linux desktop backends (PR #13): `src/platform/x11.zig`, `src/platform/wayland.zig`, `src/platform/services.zig`.

## Objective

Keep first-class Linux desktop behavior complete: X11 iconic/shaded windows stay hidden when `_NET_WM_STATE` lacks HIDDEN, and incoming paste/DnD still decode Cyrillic/Greek 8-bit MIME plus KDE suggested-filename lists.

## In scope

1. Split X11 `wm_hidden` into `wm_net_hidden`, `wm_icccm_hidden`, `wm_unmapped`, and `wm_shaded`. `syncHidden()` ORs them. `hasNetWmState(.Hidden)` uses only `wm_net_hidden`.
2. Treat `_NET_WM_STATE_SHADED` like hidden for `present()` / expose-on-leave.
3. Decode ISO-8859-5 / ISO-8859-7 MIME and COMPOUND_TEXT `ESC - L` / `ESC - F`.
4. Accept `application/x-kde-suggestedfilename` as a desktop file MIME.

## Out of scope

- UI chrome (`src/client/`) and the comic renderer
- Full IME editor, AT-SPI/UIA, dedicated drop Event
- Wayland taskbar urgency, `_NET_WM_SYNC_REQUEST`
- Outgoing source DnD / `xdg_toplevel_drag`
- COMPOUND_TEXT 94ⁿ CJK (optional; do not block)
- `ext-data-control` / `wlr-data-control` (optional; do not block)
- `application/vnd.portal.filetransfer` (no decoder yet)
